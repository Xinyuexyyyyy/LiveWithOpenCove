# 工作区性质

## 工作区名

`maker`

## 核心目标

独立开发者的产品工作区。当前主项目是 `notebook-cli` — 一个本地优先的命令行笔记工具，目标是替代 Obsidian + Alfred + grep 的组合。

## 服务对象

我自己作为 indie maker 的角色。所有跟"做产品 / 写代码 / 跑用户测试"相关的事情都在这里。

## 不在这里做的事

- 写文章、写公众号 → `writer` 工作区
- 学术论文阅读、综述 → `researcher` 工作区
- 个人财务、生活杂事 → 不进任何工作区
