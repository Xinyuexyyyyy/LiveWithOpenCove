# Lessons

## 2026-05-12: 标题里的"误解"比"真相"回流更高

**场景：** newsletter#47 原标题是"上下文工程的真相"，发布前 1 小时改成"关于上下文工程的几个误解"。

**观察：** 这是我写过回复最多的一篇（84 条）。后来观察类似主题的其他作者，"误解 / 错误 / 陷阱"类标题的打开率普遍高于"真相 / 本质 / 核心"。

**做法：** 后续选题时，如果有"X 的几个误解"这样的角度可写，优先于"X 是什么"。

**效果：** 还在验证，但 #47 的转发率确实高出平均一倍。

**置信度：** 中（单次样本，需要再观察 3-5 期）

**建议：** 做"误解 / 真相"的二选一时，先写"误解"版本。但不要硬凑，没有真正的误解就别用这个标题模板。

## 2026-04-30: 读者问最多的不是文章主题，是文章里的某个比喻

**场景：** newsletter#45 主题是"工具的复杂度从哪来"，但回复里 60% 是在追问我用过的"扳手类比"（说 LLM 工具像没有把手的扳手）。

**观察：** 读者更容易记住具体场景和比喻，而不是抽象论点。我以为我在讲一个论点，读者其实在跟着比喻走。

**做法：** 之后写作前先想"读者会记住哪一个具体画面"。如果想不出来，说明这篇还没成型。

**效果：** newsletter#48 写之前就先定了"agent 自己 grep 我硬盘"这个画面，下笔顺多了。

**置信度：** 高

**建议：** 中长文不要靠"论点连贯"撑着读者，要靠"具体画面"勾着读者。

## 2026-03-22: "下篇见"是劣势，不是钩子

**场景：** 早期写连载时结尾都加"下篇我们继续聊 X"，以为是引发期待。

**观察：** 加"下篇见"的那几期，第二篇的打开率反而低于其他文章。听一个朋友说："看到'下篇见'我就觉得这篇没写完。"

**做法：** 现在每篇都自成立，不依赖下一篇。如果是连载，标题里写清楚"#1 / #2"，但正文不留悬念。

**效果：** 这次连载第一篇的回流明显比之前的连载好。

**置信度：** 中

**建议：** 连载靠"主题持续吸引"撑，不靠"剧情钩子"撑。Cliffhanger 是小说的工具，不是 essay 的工具。
