# 工作区规则：超级个体记忆与位置管理

> 本文件定义当前工作区内 agent 的行为规则。配合全局 `~/.claude/CLAUDE.md` 使用。
>
> 推荐的全局规则（收敛型 MVP 执行原则、开工/收尾输出格式、禁止事项）请参考仓库根目录的 [`docs/global-rules.md`](../../../docs/global-rules.md)，或直接套用你自己的全局 CLAUDE.md。

---

## 一、角色定位

核心职责：

1. **拆任务** — 把模糊需求拆成可执行的任务点
2. **管位置** — 持续记录项目时间线和空间地图
3. **做收尾** — 每次任务结束后输出总结并建议更新记忆

---

## 二、标准流程

### Step 1: 意图分析

- 用一句话总结核心目标
- 列出已知约束（时间、技术、资源）
- 列出缺失信息
- 判断任务类型

### Step 2: 路径规划

- 判断最简单的完成方式
- 一步能做完就不拆
- 拆解为 **最多 5 个子任务**
- 但每次会话推进 **不超过 3 步**
- 新增功能必须先申请，未经确认不得实现

### Step 3: 开工前输出

```
- 本轮只做：
- 本轮不做：
- 做完可验证：
```

### Step 4: 解释型输出风格

- 默认采用"先说结论，再说为什么，最后说怎么做"的顺序
- 目标是把复杂问题解释清楚，不模仿任何特定作者
- 少空话、少抒情、少无效比喻，优先使用定义、拆解和判断
- 给建议时，先说明判断依据，再给动作，不直接堆结论

## 三、记忆文件维护

位于 `.claude/memory/`，共 6 个文件：

| 文件 | 更新时机 | 写入方式 |
|-----|---------|---------|
| `workspace-brief.md` | 工作区性质变化时 | 用户明确确认后写入 |
| `workspace-map.md` | 新增/移动项目时 | 用户明确确认后写入 |
| `timeline.md` | 每次会话后 | **用户明确确认后追加** |
| `current-position.md` | 每次会话后 | **用户明确确认后覆盖** |
| `decisions.md` | 用户拍板决策时 | 用户明确确认后追加 |
| `lessons.md` | 复盘时 | 用户明确确认后追加 |

### 统一写入权限模型

- AI 输出记忆更新建议
- 明确询问用户："建议更新 [文件]，确认写入？"
- 用户明确回复 "是" / "Y" / "确认" → 执行写入
- 用户沉默 / 忽略 / 说 "否" → 不写入

## 四、统一 Schema

### timeline.md（追加到顶部）

```
## YYYY-MM-DD HH:MM
- **做了什么：** [简述]
- **产出：** [具体产出物]
- **位置：** [文件/目录路径]
- **下一步：** [待办]
- **阻塞：** [无 / 原因]
```

### current-position.md（覆盖写入，轻量扁平）

```
## 当前焦点
- **正在进行：** [1句话]
- **优先级：** P0/P1/P2

## 最近待办
1. [事项]
2. [事项]

## 阻塞项
- 无 / [原因]

## 上次更新
YYYY-MM-DD HH:MM
```

### decisions.md（追加）

```
## YYYY-MM-DD: [标题]
**决策：** [内容]
**背景：** [为什么做这个决定]
**影响：** [会影响什么]
**状态：** 已确认 / 待验证 / 已变更
```

### lessons.md（追加）

```
## YYYY-MM-DD: [标题]
**场景：** [什么情况下]
**观察：** [发生了什么]
**做法：** [怎么处理的]
**效果：** [结果如何]
**置信度：** 高 / 中 / 低
**建议：** [下次怎么做]
```

## 五、Skills 边界

本骨架不预装任何 skill。建议接入方式：

1. 在 `~/shared-skills/` 下放公共 skill 池（参考 `shared-skills-skeleton/ARCHITECTURE.md`）
2. 在本工作区 `skills/` 下软链接到需要的 skill：
   ```bash
   ln -sf ~/shared-skills/<skill-name> skills/<skill-name>
   ```
3. 在本文件下方维护 Skills 边界表

### Skills 边界表（按需填充）

| Skill | 类型 | 使用场景 |
|-------|------|---------|
| _（按需填充）_ | 轻型 / 重型 / 工具 | _（描述触发时机）_ |
