# Lessons

## 2026-05-19: 同一组论文，过两遍能看出第一遍没看到的结构

**场景：** constrained decoding 这 38 篇论文我 4 月就读过一遍，写了笔记。5 月写综述时再过一遍，发现三篇被引最多的论文其实在解决三个不同问题，过去我笔记里全归到"一类"里。

**观察：** 第一遍读是"理解每篇在说什么"，第二遍读才能"看出论文之间的关系"。这是两个不同的认知任务，不能合并。

**做法：** 后续文献阅读分两阶段：第一轮"逐篇笔记"，第二轮"主题聚类"。两轮之间至少隔两周。

**效果：** 综述第二章因为这次聚类的结构清晰多了，写得顺多了。

**置信度：** 高

**建议：** 综述写作前一定要做"主题聚类"这一步，不要直接从笔记下笔。

## 2026-03-15: 文献囤积是焦虑的伪装

**场景：** 前一个项目（LLM-uncertainty）失败 6 个月内，我下载了 200+ 篇论文，认真读完的只有 60 篇左右，但每天都在"再下载几篇"。

**观察：** 持续下载论文给了我"在推进研究"的错觉。实际推进 = 写出综述 / 跑出实验，下载本身不是推进。

**做法：** 这个项目设硬规则 — 周一定文献，周内不新加。如果发现"必须新读"的论文，先记到 candidate 档，下周一统一评估。

**效果：** 文献库总量比上个项目小 70%，但读完率从 30% 升到 75%。

**置信度：** 高

**建议：** 文献库的健康指标不是数量，是"已读 / 已笔记"比例。低于 60% 就停下载。

## 2026-02-28: 跟领域专家访谈前要先做实验

**场景：** 上个月跟医疗信息学专家访谈 90 分钟，最有价值的洞察来自我提到 baseline 实验的 23% 格式错误率时，他给出的"临床上最不能容忍非标准化同义词"的回答。

**观察：** 如果我没跑过 baseline，没有那个 23% 的数字，专家就只能给"通用建议"。有具体数据后，对话立刻进入"为什么这 23% 里的 X 比 Y 重要"的深度。

**做法：** 后续找专家访谈前，至少跑一个 baseline 实验，带着真实数据去聊。

**效果：** 这次访谈的洞察改变了整个综述的问题陈述方向，价值远超 90 分钟。

**置信度：** 高

**建议：** 不要把"专家访谈"当成"研究的开始"，要当成"实验之后的解读环节"。
