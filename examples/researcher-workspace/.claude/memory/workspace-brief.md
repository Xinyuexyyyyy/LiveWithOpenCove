# 工作区性质

## 工作区名

`researcher`

## 核心目标

独立研究项目 SLM-controllability — 探索小型语言模型（< 7B 参数）在专业领域（当前选医疗术语规范化）的输出可控性。当前是项目第一阶段：文献综述 + 实验设计。

## 服务对象

我自己作为独立研究者的角色。研究是没有上级的，所以这个工作区也承担"自我约束"的功能 — 防止读着读着就跑偏，防止文献越囤越多但论点不收敛。

## 不在这里做的事

- 写代码工具、做产品 → `maker` 工作区
- 写公开文章、newsletter → `writer` 工作区
- 跟外部合作者沟通 → 邮件 + Notion，不进工作区
