## 2026-04-10: PoC 实现选 token-tree-based，不选 grammar-based

**决策：** 第一个 PoC 实验用 token-tree-based constrained decoding（参考 Outlines 项目）。

**背景：** 三类方法都试想过。Grammar-based（GBNF）需要为每个任务写 BNF 文法，对医疗术语库规模（10w 条）不现实。Logits-bias 太粗粒度，难以保证完整匹配。Token-tree 在性能和精度上是折中选择。

**影响：**
- 实验代码会基于 Outlines 改，不从零写
- 评估指标除了准确率，还要看 latency overhead（这是 token-tree 的主要代价）

**状态：** 已确认
