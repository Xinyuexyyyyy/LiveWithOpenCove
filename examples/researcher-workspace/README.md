# Researcher Workspace（示例）

> 这是 LiveWithOpenCove 提供的示例工作区之一：**做研究的我**。
>
> 内容全部为虚构。研究类工作区跟 maker / writer 都不一样：节奏更慢，产出周期更长（一个项目可能跑 3-6 个月），timeline 记的不是"今天写了什么"而是"今天读了什么 / 验证了什么 / 卡在哪"。

## 角色设定（虚构）

"我"是一个独立研究者，正在做一个关于"小型语言模型在专业领域的可控性"的项目。当前在做文献综述阶段，准备写第一份内部报告。

## 怎么用

```bash
cp -r examples/researcher-workspace ~/my-research-workspace
```

## 跟 maker / writer 工作区的对比

| 维度 | maker | writer | researcher |
|-----|-------|--------|-----------|
| 时间尺度 | 周 | 周 | 月-季 |
| 产出 | 代码 / 功能 | 文章 | 综述 / 报告 / 论文 |
| 主要外部输入 | 用户反馈 / bug | 读者回复 | 论文 / 数据 / 实验结果 |
| timeline 长什么样 | commit / 实验 | 写作进度 | 读了什么、跑了什么、卡在哪 |

研究的"卡住"是常态，所以 lessons 里特别多"为什么卡住"的复盘。
